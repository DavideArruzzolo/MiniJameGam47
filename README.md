## 📝 Description
After a cloning experiment goes wrong, the Eggheadz make their escape!. Use your head (all 4 of them!) to jump, dash, press, and flash through a short but tough gauntlet of puzzles. The goal of the game is to reach the door at the end of each level. 

* **The Theme ("Cheap Copy"):** Implemented as the cloning mechanic. A clone is a "cheap copy" and deteriorates from the original egg with each copy by losing abilities.
* **Special Object ("Egg"):** This is why the protagonist is an egg.

### 🧩 Gameplay Mechanics
* **Cloning Limitations:** Every clone you make has fewer abilities. The first clone can't double jump, the second loses the ability to dash, and the third can only walk.
* **Interactions:** Most doors are closed by default, and need to be opened by interacting with levers and buttons. Buttons are pushed automatically when touched, but levers need to be interacted with. 
* **Clone-Specific Puzzles:** If a button or lever has a colored egg icon above it, it means that it can only be used by that clone. These can also disable and enable walls marked with numbers.

## 🕹️ Controls
* **Walk:** Arrows / WASD
* **Jump:** Space / Z
* **Double Jump:** Press the jump button twice
* **Dash:** Shift
* **Clone:** C
* **Switch Clones:** Tab
* **Interact (Levers):** X
* **Reset Level:** R
